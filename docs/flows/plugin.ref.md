## Reference

Every function of the `plugin` flow: what it takes, what it returns, what it refuses, and how it undoes. A `Result<T>` is `Ok(T)` or a `SuperbError`; the errors listed are the ones you can cause.

### `scan`

```rust
pub fn scan() -> Vec<PluginDescriptor>
```

Every plugin installed where plugins are conventionally kept on this
machine, plus the folders `CLAP_PATH` names. A bundle that does not load is
skipped. Turn a result into an insert with
`Effect::Plugin(PluginRef::from(&descriptor))`.

**Returns** `Vec<PluginDescriptor>` — a descriptor per plugin found: name, vendor, id, features and the bundle's path. Empty when none is installed

**Made of** `plugins::scan::scan_default(PluginFormat::Clap)`.

**Example**

```rust
for p in plugin::scan() {
    println!("{} ({})", p.name, p.vendor);
}
```

### `params`

```rust
pub fn params(session: &mut Session, insert: InsertId) -> Result<Vec<ParamInfo>>
```

A plugin's parameters, in the plugin's order: each one's id, name, range and
default. Loads the plugin if the session has not yet.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`

**Returns** `Result<Vec<ParamInfo>>` — one `ParamInfo` per parameter, in the plugin's order: `id`, `name`, `min`, `max`, `default`

**Errors** an unknown insert; an insert that is not a plugin; a plugin that could not be loaded (the error says why).

**Undo** none: not an edit.

**Made of** `Session::plugin_loader` when needed → `LoadedPlugin::params`.

**Example**

```rust
for p in plugin::params(&mut session, verb)? {
    println!("{} {}", p.id, p.name);
}
```

### `param`

```rust
pub fn param(session: &mut Session, insert: InsertId, param: u32, value: f64) -> Result<()>
```

Sets one parameter of a plugin, by the id `params` lists, to a plain value
inside its range. Heard at the plugin's next block. Moves within
`Session::COALESCE_WINDOW` of each other are one undo step.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`
- `param: u32` — the parameter's id, from `plugin::params`
- `value: f64` — a plain value inside the parameter's range

**Returns** `Result<()>` — nothing

**Errors** an unknown insert or parameter; a value outside the parameter's `min..=max` or not finite; a plugin that could not be loaded.

**Undo** one undo step per drag: calls within `Session::COALESCE_WINDOW` (half a second) merge; the running plugin gets the value at its next block, and an undo sends the old one.

**Made of** `set_insert_param` through `session::edit` → `PluginHandle::params` (the running plugin's parameter queue).

**Example**

```rust
plugin::param(&mut session, verb, mix.id, 0.3)?;
```

### `value`

```rust
pub fn value(session: &mut Session, insert: InsertId, param: u32) -> Result<f64>
```

The value a parameter has right now, read from the plugin: what `param` set,
or what the plugin moved it to itself.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`
- `param: u32` — the parameter's id, from `plugin::params`

**Returns** `Result<f64>` — the parameter's value as the plugin reports it now

**Errors** an unknown insert or parameter; a plugin that could not be loaded; a format that cannot be read while it runs.

**Undo** none: not an edit.

**Made of** `Session::plugin_loader` when needed → `LoadedPlugin::value` (`PluginControl::param_value` while the plugin runs).

**Example**

```rust
let wet = plugin::value(&mut session, verb, mix.id)?;
```

### `changes`

```rust
pub fn changes(session: &mut Session, insert: InsertId) -> Result<Vec<PluginChange>>
```

What the plugin changed itself since this was last asked, in order: a
control taken hold of in the plugin's own view (`PluginChange::Touched`),
each value it was moved to (`Value`), and the control let go (`Released`). A
plugin may also move a parameter with no gesture around it. Ask regularly
while a control for the plugin is on screen, and draw what comes back; each
call hands the changes out once.  A value the plugin reports goes into the
memory as `param` would put it, without being sent back to the plugin: it is
saved with the session, and undo returns the parameter to what it was
before. `session::save` takes the values in too, so nothing is lost if this
is never called. A change is heard after the block it happens in, so none
arrive while no audio is running.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`

**Returns** `Result<Vec<PluginChange>>` — each `PluginChange` the plugin reported since the last call, in order: `Touched { id }`, `Value { id, value }`, `Released { id }`. Empty when it changed nothing

**Errors** an unknown insert; an insert that is not a plugin; a plugin that could not be loaded.

**Undo** one undo step per drag: calls within `Session::COALESCE_WINDOW` (half a second) merge, for each value the plugin reports; the value is not sent back to the plugin, and an undo sends the one before.

**Made of** `PluginNode::take_change_receiver` (the queue the running plugin reports on) → `set_insert_param` through `session::edit` per parameter moved.

**Example**

```rust
for change in plugin::changes(&mut session, verb)? {
    if let PluginChange::Value { id, value } = change {
        println!("{id} is now {value}");
    }
}
```

### `missing`

```rust
pub fn missing(session: &Session) -> Vec<(InsertId, SuperbError)>
```

The plugin inserts of the session whose plugin could not be loaded, each
with the reason. They stay in the session, are saved as they were, and are
left out of the mixer.

**Takes**
- `session: &Session` — the open session, borrowed

**Returns** `Vec<(InsertId, SuperbError)>` — each plugin insert whose plugin is not loaded, with the error the loader gave

**Example**

```rust
for (insert, why) in plugin::missing(&session) {
    println!("{insert:?}: {why}");
}
```

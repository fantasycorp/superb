## Reference

Every function of the `insert` flow: what it takes, what it returns, what it refuses, and how it undoes. A `Result<T>` is `Ok(T)` or a `SuperbError`; the errors listed are the ones you can cause.

### `add`

```rust
pub fn add(session: &mut Session, track: TrackId, effect: Effect) -> Result<InsertId>
```

Adds an effect at the end of a track's insert chain: the signal runs through
the chain in order, then into the fader. Any track takes inserts, buses and
the master included. The effect starts at its defaults; set its parameters
with `param`, or a plugin's with `plugin::param`. A plugin
(`Effect::Plugin`) is loaded here, and refused if it cannot be.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `track: TrackId` — the track, bus or master (`session.memory.master().id()`) whose chain gets the effect
- `effect: Effect` — `Effect::Compressor`, `Limiter`, `Gate`, `DeEsser` or `Leveler`; `Effect::Plugin(PluginRef)` is stored but not heard

**Returns** `Result<InsertId>` — the new insert's id

**Errors** an unknown track.

**Undo** one undo step; rebuilds the mixer (at once while a device plays, otherwise at the next start).

**Made of** `Memory::allocate_insert_id` → `Insert::with_id` → for a plugin, `Session::plugin_loader` → `AddInsert` through `session::structural`; rebuilds the mixer.

**Example**

```rust
let comp = insert::add(&mut session, vox, Effect::Compressor)?;
```

### `remove`

```rust
pub fn remove(session: &mut Session, insert: InsertId) -> Result<()>
```

Removes an insert. Undo puts it back where it was, parameters and all; a
plugin is loaded again in the state it was removed in.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`

**Returns** `Result<()>` — nothing

**Errors** an unknown insert.

**Undo** one undo step; rebuilds the mixer (at once while a device plays, otherwise at the next start); undo puts it back at its place with its parameters.

**Made of** for a plugin, its state into `Insert::preset` → `RemoveInsert` through `session::structural`; rebuilds the mixer.

**Example**

```rust
insert::remove(&mut session, comp)?;
```

### `move_to`

```rust
pub fn move_to(session: &mut Session, insert: InsertId, index: usize) -> Result<()>
```

Moves an insert to `index` in its track's chain; `0` is first.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`
- `index: usize` — the place in the track's chain; `0` is the first effect the signal meets

**Returns** `Result<()>` — nothing

**Errors** an unknown insert; an index past the end of the chain.

**Undo** one undo step; rebuilds the mixer (at once while a device plays, otherwise at the next start).

**Made of** `MoveInsert` through `session::structural`; rebuilds the mixer.

**Example**

```rust
insert::move_to(&mut session, comp, 0)?;   // first in the chain
```

### `param`

```rust
pub fn param( session: &mut Session, insert: InsertId, param: EffectParam, value: f32, ) -> Result<()>
```

Sets one parameter of an effect, in the unit its `EffectParam` names (dB,
milliseconds, Hz). Heard at the next block. Moves within
`Session::COALESCE_WINDOW` of each other are one undo step.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`
- `param: EffectParam` — which control: `EffectParam::Threshold`, `Ratio`, `Attack`, `Release`, `Knee`, `Makeup`, `Ceiling`, `Hold`, `Range`, `Frequency`, `Target`, `Speed`, `Floor`
- `value: f32` — in the parameter's unit: dB for levels, milliseconds for times, Hz for a frequency, `n` of `n:1` for a ratio

**Returns** `Result<()>` — nothing

**Errors** an unknown insert; a parameter the effect does not have (`Effect::params` lists them); a value that is not finite.

**Undo** one undo step per drag: calls within `Session::COALESCE_WINDOW` (half a second) merge; the running effect hears it at once.

**Made of** `Effect::has` → `set_insert_param` through `session::edit` → `InsertParams::set` on the running effect.

**Example**

```rust
insert::param(&mut session, comp, EffectParam::Threshold, -24.0)?;
insert::param(&mut session, comp, EffectParam::Ratio, 4.0)?;
```

### `bypass`

```rust
pub fn bypass(session: &mut Session, insert: InsertId, on: bool) -> Result<()>
```

Bypasses an insert or puts it back in circuit. State, like mute: saved with
the session, not an undo step. A built-in effect rebuilds the mixer, which
is built without it; a plugin stays loaded and is switched at the next
block.

**Takes**
- `session: &mut Session` — the open session, borrowed mutably
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`
- `on: bool` — `true` to bypass, `false` to put it back in circuit

**Returns** `Result<()>` — nothing

**Errors** an unknown insert.

**Undo** none: state, not an edit (saved through the state file, see `session::state_file`); rebuilds the mixer (at once while a device plays, otherwise at the next start).

**Made of** `InsertState::bypass` through `session::set_state` → rebuild, or for a plugin `PluginHandle::bypass` on the running node.

**Example**

```rust
insert::bypass(&mut session, comp, true)?;
```

### `reduction`

```rust
pub fn reduction(session: &Session, insert: InsertId) -> Option<f32>
```

How much an effect was turning the signal down at the end of the last block,
in dB, for a gain-reduction meter. `None` for a plugin insert, which reports
no reduction, and for a built-in effect that is not in the mixer: bypassed,
or added since the last rebuild.

**Takes**
- `session: &Session` — the open session, borrowed
- `insert: InsertId` — the insert's id, from `insert::add` or `track.inserts()`

**Returns** `Option<f32>` — dB taken off at the end of the last block (zero or more; a leveler that is turning the signal up reads below zero), or `None` for a plugin insert and for a built-in effect not in the mixer (bypassed, or added since the last rebuild)

**Errors** never; a query.

**Undo** none.

**Made of** `MixerHandles::insert` → `InsertParams::reduction_db`.

**Example**

```rust
if let Some(db) = insert::reduction(&session, comp) {
    println!("-{db:.1} dB");
}
```
